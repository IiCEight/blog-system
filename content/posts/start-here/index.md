Most useful notes begin before the idea is ready. A sentence, an observation, a question you haven't answered yet.

This is a **sample entry** so you can try the design. Your original notes remain plain Markdown files.

## Start with a sentence

When an idea appears, give it somewhere to live. A title and a date are enough to begin.

> Capture the thought while it is yours. You can give it structure tomorrow.

- What did I notice?
- What surprised me?
- What would I like to understand next?

## Leave room to return

Keep the original creation date when you refine a note. Set `lastmod` to record a meaningful update.

| Moment | What to keep |
| --- | --- |
| First thought | A sentence and a date |
| Later understanding | An explanation or example |
| A new connection | A link to another note |
