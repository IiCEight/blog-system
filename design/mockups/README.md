# Frontend review

Open `index.html` in a browser. No server, dependency installation, or network connection is required.

The homepage links to `article.html`. Search filters the sample notes, excerpts expand, and article contents links navigate to headings. All displayed notes are fictional design samples. “Fieldnotes” is a proposed working title, not a confirmed name.

These are standalone visual prototypes, not a Hugo implementation. They do not provide authentication or publishing, and must not be uploaded with real private content as a production site. System fonts are used for a self-contained first review; final font choices can follow feedback.

Review the typography, raspberry, bright pink, and soft white palette, homepage density, and article reading layout. Homepage and article responsiveness should be inspected in a browser before claiming visual verification.
